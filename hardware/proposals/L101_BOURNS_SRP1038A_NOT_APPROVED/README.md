## 参数与未实测边界

[Bourns原厂](https://www.bourns.com/docs/product-datasheets/srp1038a.pdf)列出10µH±20%、DCR最大30mΩ、Irms7.5A（规定测试条件下温升40°C）、Isat12A（25°C下降20%）；这些不是热态全条件最小值。原型号DCR最大16.5mΩ，换型会增加绕组损耗。未采用更小的4A Irms型号作为当前候选。

按25.2V输入、输出5.5V上界、400kHz、3.5A负载、L=6.4µH等**工程保护性假设**，同时计入1V续流压降和估计热态绕组压降，算得纹波1.950A、峰值4.475A、RMS3.545A。峰值很接近[TI](https://www.ti.com/lit/ds/symlink/tps54360b.pdf)规定的4.5A最低开环限流；这不保证全角落3.5A输出，实际负载预算与瞬态余量必须继续闭合。25°C绕组损耗估计0.377W、125°C估计0.525W，均未包含已测核心/交流损耗。

短路灵敏度计算用6.8A最高开环限流及**假定120ns**延迟得7.273A；TI只有60ns典型延迟，120ns不是保证上界。热态电感、完整频率折返、短路/恢复、补偿和实际温升均留待进一步设计审查及首板测试；本候选 **没有实测PASS，也没有POWER_SAFETY_REVIEW=PASS**。完整输入/假设/输出在 `PARAMETER_SCREEN.json`。

[立创对应记录](https://www.lcsc.com/product-detail/C780184.html)已核对完整型号；不混用`SRP1038AA-100M`。库存与最终采购条件尚须实际确认；未采购、未下单。批准新型号与制造放行是独立事项。`FORMAL_REPLACEMENT_APPROVED=NO`、`FABRICATION_READY=NO`。

本候选保留当前正式MCU/测点位置；未包含未批准的紧凑晶体或USB新电源集成。正式采用需人工确认新exact MPN，再按差异集成并对最新正式源重新检查。
