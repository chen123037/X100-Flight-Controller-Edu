# 中英文术语表
## Chinese-English Engineering Glossary

术语中文说明帮助读图，英文标识在工程中保持原样。下面的释义不构成本板已经制造、测试或飞行通过的声明。

| English / 标识 | 中文名称 | 教学解释 / 本板关联 |
| --- | --- | --- |
| MCU | 微控制器 | 整合CPU、存储与外设的控制芯片；本板为U201 |
| IMU | 惯性测量单元 | 加速度与角速度传感；本板BMI088 |
| Barometer | 气压计 | 测气压供高度估计，不等于绝对高度已校准 |
| Buck Converter | 降压转换器 | 开关方式把高输入电压降到所需电源 |
| LDO | 低压差线性稳压器 | 以线性方式稳压，需输入输出压差及热预算 |
| ESD | 静电放电 | 静电产生的瞬态；器件保护不等于整板认证 |
| TVS | 瞬态电压抑制 | 限制瞬态电压的保护器件，需能量/时序协调 |
| CAN Transceiver | CAN收发器 | 逻辑CAN_TX/RX与CANH/CANL差分总线之间转换 |
| CAN Termination | CAN终端匹配 | 总线端点匹配电阻；本板120Ω由JP601启用 |
| UART | 通用异步串口 | 发送TX/接收RX；本板外部逻辑3.3V，不是RS232 |
| I2C | 两线串行总线 | 开漏时钟SCL和数据SDA，需要正确上拉与地址 |
| SPI | 串行外设接口 | 时钟/数据/片选同步通信；本板BMI088板内SPI1 |
| SDMMC | SD/MMC接口 | 存储卡控制接口；本板SDMMC1四位总线 |
| PWM | 脉宽调制输出 | 信号占空/脉宽控制，本板六路不带电源脚 |
| ADC | 模数转换输入 | 把模拟电压转成数字值，量程/比例需校准 |
| SWD | 串行线调试 | SWDIO/SWCLK调试，VTref是目标电压参考 |
| PCB | 印制电路板 | 铜导体、绝缘材料与孔组成的电路载体 |
| Footprint | 封装焊盘图形 | PCB中器件的焊盘、孔、本体与装配标记集合 |
| Pad | 焊盘 | 元件焊接/连接的铜区域，可为表面或通孔 |
| Via | 过孔 | 连接铜层的孔；当前正式via为0 |
| Copper Zone | 铺铜区 | 指定网络的铜区域；当前正式zone为0 |
| Ground Plane | 接地平面 | 连续GND参考与回流铜层，In1为冻结目标 |
| Net | 网络 | 原理图/PCB中的电气连接集合，名称不可擅自改 |
| Net Class | 网络规则类 | 按电气用途分配走线宽度/间距等规则 |
| DRC | 设计规则检查 | 检查PCB的间距、连接、几何等规则，不保证实物所有性能 |
| ERC | 电气规则检查 | 检查原理图电气类型与连接规则，不代替样机测试 |
| Differential Pair | 差分对 | 成对传输差分信号的两根线，如USB_DP/USB_DM |
| Impedance | 阻抗 | 交流传输中电压/电流关系；取决于材料和几何 |
| Silkscreen | 丝印 | 器件编号、极性和接线标记，不是实际铜 |
| Solder Mask | 阻焊层 | 覆盖铜的绝缘涂层及焊盘开窗 |
| Paste | 锡膏层 | 钢网印刷锡膏的开口；JP601为NO PASTE |
| Courtyard | 器件装配边界 | 装配间距元数据，不能代替真实三维碰撞核验 |
| Keepout | 禁布区 | 禁止指定铜/器件/过孔等进入的区域 |
| Bring-up | 首板调试/上电验证 | 从外观、断电阻值、限流供电到模块/固件验证 |
| DFM | 面向制造设计 | 检查工艺、加工、装配、返修与机械可实现性 |
| CPL | 贴片坐标文件 | Reference、位置、旋转和面别等贴装数据 |
| NPTH | 非金属化孔 | 无孔壁铜的定位/安装孔，如H1–H4 |
| DNP | 默认不装 | 必须有明确装配标志；NC脚/OPEN焊桥不自动等于DNP |
| ECO | 工程变更 | 受控修改设计，需范围、核验和人工技术边界 |
| MPN | 厂家订货型号 | 精确采购身份；普通阻容的优选MPN不等于唯一来源 |
| PDB | 配电板 | 分配动力电流与飞控支路，推进电流不走飞控PCB |

相关状态见[功能成熟度矩阵](FEATURES.md)，所有接线以[接口定义](INTERFACES.md)为准。
