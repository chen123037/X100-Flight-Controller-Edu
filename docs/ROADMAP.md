# X100 当前剩余工作

当前起点是[六层V4](../hardware/current/X100_6L_DFM_ZERO_DANGER/)，已0未连接、ERC0、DRC0错误/0parity，实际PCB DFM所报危险0。旧c8的96条未连接和四层重排已是历史，不重新从那里开始。

1. **完成整板热设计判断。** 对U101/D103保留6S、高负载和环境条件，闭合实际铜散热/互热及有效热阻接受；不把模型/典型值当实测，也不把未完成分析单纯推给首板。
2. **实际板厂审稿。** 使用当前唯一制造ZIP，确认JLC06161H-3313、外1oz/内0.5oz、1.6mm、沉金、高精字符及树脂填孔＋盖帽范围。安装孔、插孔、USB槽保持通畅，生产稿变动必须可复核。
3. **装联与采购。** 当前62种MPN/142件与源图一致；结合已有裁决核对候选字段和供货。原生CPL、钢网、拼板、工艺边、双面焊接及来料验真分别审核，不沿用旧CPL。
4. **最终人工制造接受。** 已有DFM0不自动填其它PASS；归档工厂生产稿、真实风险结论和最终订单文件身份。不自动付款或下单。
5. **首板与飞行。** 断电检查、限流上电、USB冷启动/枚举/挂起及双源切换、SD日志、CAN待机、传感器、ADC与六路输出安全偏置、温升/故障测试；再进行固件、无桨台架和经人工批准的分级飞行。
