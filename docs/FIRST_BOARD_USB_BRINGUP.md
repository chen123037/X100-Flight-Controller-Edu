# X100 首板 USB-only Bring-up 测试计划

2026-10-22。当前无实板、无开发板测试；本文件是待执行计划，没有实测 PASS。用户不要求为本任务额外购买开发板。制板前继续原厂资料、网络、几何、制造审查；首板取得后再使用可借用/实验室仪器完成下列记录。

## 测试前输入

记录板版本/制造包SHA256、实际BOM/PCB叠层、MCU硅revision、bootloader与固件提交、USB描述符、时钟/VOS/温区与仪表带宽。核心电源分区、限流选择和电容必须与最终批准方案一致。当前Stage3只是未批准候选，器件号可能随布局更改。

## 必测项目及判据

| 项目 | 条件及记录 | 判据/后续 |
| --- | --- | --- |
| 断电检查 | 电源与GND电阻、USB DP/DM/CC/Shield、限流默认状态、焊接极性 | 排除装配短路、错件和错脚后上电；保持测试照片与原始读数 |
| 限流台架首次上电 | 无VBAT，逐步上电；观测USB输入、5V_CORE_MUX、5V_CORE、3V3_MCU、NRST、PE3 | 无过热/反灌；复位仅在电源有效后释放。若受限反复复位，记录阈值和时间，不靠取消限流绕过 |
| 枚举前/浪涌 | A→C、C→C各至少两种电脑/线缆；冷插与慢升；同时测原始VBUS电流及电压波形 | 枚举前总输入≤100mA，并按USB-IF方法检查浪涌；不能仅看USB表低速平均值。需确认原厂限流最小角落仍能启动 |
| 配置后供电 | 验证主机接受500mA描述符，PE3随后才切换；不假定1.5A | 输入及瞬态符合获准电流；电源稳定。主机未配置/拒绝配置时保持低负载 |
| 刷写/恢复 | 无VBAT、无SD及插SD，各执行bootloader枚举、擦写、校验、复位、应用枚举 | 数据校验一致，USB不断连失控，无卡可进入基本配置；记录峰值电流/最低电源电压 |
| 参数与传感器 | 地面站连接、读写参数、断电保持；BMI088/SPL06检测与桌面校准 | MCU/USB稳定，参数Flash分区正常；确认传感器电源有效后才驱动IO |
| SD隔离 | 插卡与不插卡；USB-only和VBAT；量3V3_SD及六条SDIO，检查上/掉电时序 | USB-only卡支路不拖垮核心；无寄生供电超规格；VBAT时SD_PG后才能开放总线 |
| 挂起与恢复 | 主机真正USB suspend，记录描述符和host事件；热态/冷态；禁止以持续通信避免挂起 | 原始USB输入≤2.5mA，能按协议恢复。当前仅有Stop资料不足以证明，失败后收紧低功耗实现或提出最小硬件修订 |
| 双电源变化 | USB先/电池先、两源拔任一、电脑关闭/端口断电；监测两源电流方向与所有电源轨 | 无非预期回灌、超压、异常热；按既定策略安全复位/重新枚举。不能以“无明显断电”替代波形证据 |
| 温度与容差 | 实际环境温区，记录Tj估计方法；代表性低USB电压、线损及电容/限流角落 | 与预算模型逐项比对；热态超预算时禁止宣称全温区可用 |

## 记录及失败处理

保存示波器原始文件/CSV、USB事件日志、仪表设置和测试连接图，计算总输入电流，区分峰值、稳态、时间平均与积分电荷。启动、挂起、切换、电源轨、Flash和IO隔离分别给结果；某项通过不能替代其余项目。

若首次启动电流超过预算，优先核查外设提前启动、IO寄生供电、限流选择和复位时序，再评估最小BSP/硬件修订。不擅自把低档升至500mA、不要求电脑提供1.5A、不并联USB与5V_MAIN。发现反灌/超压/过热时停止该次上电并保存证据；未测项目继续保持NOT_TESTED。

最终制造文件几何审查与上述实物功能测试分别记录；本计划不批准采购、实际下单或飞行。
